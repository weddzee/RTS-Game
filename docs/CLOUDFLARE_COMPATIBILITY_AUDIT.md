# Cloudflare Compatibility Audit — OpenFrontIO Baseline

Baseline: `e02eeba66b4801ebae0b686e1b0e4bc03fbf3654` (2026-10-01).
Goal: browser game must remain suitable for later Cloudflare deployment
(Workers + Durable Objects + R2/Assets). This audit classifies every
server dependency and every Node-specific API.

## 1. Verdict summary

- `src/core` + `zbin`: **portable as-is** (pure TS + `zod`/`jose`/`nanoid`,
  no Node built-ins). Must stay free of Cloudflare APIs per Prompt 0.6.
- `src/server`: **requires replacement of the hosting layer**.
  Game logic (authz, validation, consensus, lobby planning) is largely
  pure and portable; the process/HTTP/WS/timer/fs substrate is not.
- No DB to migrate (in-memory + closed API today). Durability must be
  designed (DO storage/SQLite, D1/KV/R2) when the DO host lands.

## 4. Architectural blockers beyond imports

1. Stateful in-memory + sticky routing: `GameManager/Map`, `Roster`,
   `turns/intents`, `workerIndex = hash(gameID) % numWorkers`,
   `cluster.fork`. → DO per `gameID`, turn log in DO storage/SQLite,
   `name=` routing replaces `workerIndex`; coordinator replaces
   `Master/WorkerLobbyService` broadcast.
2. Timers: 100 ms `endTurn`, 1 s `tick/lobbyInfo/checkin`, 2 s prestart,
   15 s ranked long-poll, 10 min/3 h reaps. → DO alarms (single-flight,
   hibernation-aware) + input-driven turns; Cron/Queues for scheduling.
3. WS hibernation: `Client.ws` stored + `send/close/terminate/
removeAllListeners/readyState` everywhere. → `acceptWebSocket` +
   `serializeAttachment({clientID,persistentID})`, rehydrate in
   `webSocketMessage/Close/Error`; never hold sockets across hibernation.
4. Static serving: `express.static(../../static|out|maps)` +
   `sendFile` + `ejs` shell. → Workers Static Assets / R2 + CDN
   (`CDN_BASE` already abstracts this).
5. Secrets/config: `ServerEnv` (`GAME_ENV/NUM_WORKERS/TURNSTILE_SITE_KEY/
DOMAIN/INSTANCE_LETTER/API_KEY/ADMIN_BOT_API_KEY/OTEL_*/GIT_COMMIT/…`).
   → `env.*` bindings; delete `NUM_WORKERS/WORKER_ID/INSTANCE_ID/cluster`.

## 5. Recommended DO host shape (preserves GameCore purity)

- `GameCore` (`src/core`: `GameRunner`, `GameImpl`, executions,
  `Schemas`, `zbin`) — no Cloudflare imports, ever.
- `NodeMatchHost` (today: `GameServer` + client `GameRunner`) keeps
  working locally.
- `CloudflareDurableObjectMatchHost` (later): DO per match owns
  `Turn[]`/roster/votes in storage, validates via ported
  `IntentAuthorization`/`SocketIngress` logic, drives `endTurn` on
  `alarm()` + message arrival, exposes `fetch()` for HTTP and
  `WebSocketPair` for play. Lobby/indexer Worker + Queue/Cron replaces
  `Master`, `RankedCheckin`, `ClusterCheckin`.
